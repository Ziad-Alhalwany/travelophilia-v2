## Summary
- Setup Axios instance inside `src/services/apiClient.js` conforming to base `/api` URL.
- Designed smart request interceptors to automatically convert payload formats from React's internal `camelCase` state directly to `snake_case` compliant with Django REST responses.
- Developed reciprocal response interceptors transitioning Django endpoint data immediately to `camelCase` to prevent breaking legacy frontend components. 
- Integrated a comprehensive SimpleJWT Access & Refresh Token rotation strategy capturing HTTP 401s, renewing the session proactively, and re-attempting failed calls seamlessly.
- Maintained stability in existing generic mapper functions.

## Risks
- Unexpected behavior executing the retry logic continuously under edge cases (e.g. valid refresh token but authorization denied). The logic addresses this by not endlessly retrying (verified `_retry` flag).
- `toSnakeDeep` mutating certain unexpected structured data such as Map/Set, though `caseConverter` filters explicitly skip forms, blobs, and dates.
- Missing endpoints logic that rely directly on fetch without `authFetch` / `apiClient` may bypass interception rules.
